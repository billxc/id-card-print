# id-card-print · 身份证原尺寸 A4 排版

A local-first Python tool for cropping four ID-card photos and arranging them at actual size on one A4 PDF.

**本地处理 · 网页 / CLI · 透视矫正 · 圆角 · 水印 · 灰度 · JPEG 压缩**

输入 **两张身份证的正反面，共四张照片**，自动检测完整卡片边缘、透视矫正，输出单页 A4 PDF。默认按中国居民身份证卡面尺寸 **85.6 × 54 mm** 排版。

- 所有照片处理均在本地完成，不调用 OCR、AI 或上传服务。
- 支持 JPEG、PNG、HEIC 等 Pillow / pillow-heif 可读取的格式，自动应用手机照片的 EXIF 方向。
- 支持自动裁切、手动选四角、逐张预览确认。自动检测结合 Lab 颜色背景分离、四边内外颜色反差和边缘支持度，面积与长宽比只作辅助。
- 自动四角从直边中段拟合并延长求交，不直接使用圆角弧线上的点。预览和 PDF 使用约 3 mm 圆角，外接尺寸仍为 85.6 × 54 mm。圆角半径是固定近似值，不是逐张测量。
- 不修改输入图片；不保存中间卡面；不覆盖已有 PDF。
- 不修改文字、证件内容或修复缺失区域。裁切对象是整张卡片，不是只截文字区域。

## 网页版（推荐）

需要 Python 3.10+ 和 [uv](https://docs.astral.sh/uv/)。脚本通过 inline metadata 声明依赖；首次运行 uv 会下载依赖到隔离环境，不修改系统 Python。依赖安装需要网络，照片处理无需网络。

克隆仓库并启动：

```bash
git clone https://github.com/billxc/id-card-print.git
cd id-card-print
uv run web.py
```

下文所有命令都在克隆后的仓库根目录运行。

打开 **http://127.0.0.1:8765**。

1. 分别上传第一张、第二张身份证的正面（人像面）和反面（国徽面），支持拖放。
2. 上传后弹出裁切窗口，自动检测四角；若检测失败，直接在照片上点击四个外角。
3. 拖动蓝色圆点调整边界；也可用 Tab 选中圆点，再用方向键移动 1 pixel，Shift + 方向键移动 10 pixels。
4. 点击「更新预览」核对透视矫正后的卡面；倒置时点击「旋转 180°」。如果边缘残留黑边，用「向内裁切（每边）」先试 2–4 px，改动后自动更新预览。每个卡面独立保存，默认 0 px，上限 20 px；按 300 DPI 卡面的像素计算，换成 600 DPI 或低分辨率预览时内缩比例保持一致。四边裁后轻微放大填回 85.6 × 54 mm，原始四角不变，注意避免裁掉文字。
5. 点击「确认并使用此卡面」。四张全部确认后，页面右侧展示 A4 排版，并启用「下载 A4 PDF」。
6. 选择 300 / 600 DPI，下载 PDF；打印仍须选择「实际大小 / 100%」。

照片每张最多 **12 MB、25 MP**。支持 JPG、PNG、HEIC 等；浏览器无法直接解码 HEIC 也没关系，由本机 Python 转成预览图。预览使用较小的 JPEG，最终 PDF 仍由上传的原始照片重新裁切，不使用网页预览图作为打印源。

### 高质量 JPEG 压缩（默认开启）

网页导出默认勾选「高质量 JPEG 压缩」，将裁切后的卡面编码为质量参数 **95** 的 JPEG，启用优化编码，彩色图使用 **4:4:4**（不做色度降采样），然后直接嵌入 PDF。300 / 600 DPI 仍决定图片的像素尺寸，卡面打印尺寸和圆角不变，文字水印继续使用独立的矢量绘制。

这是高质量有损压缩，适合照片，可减少通常较大的无损图像数据；实际文件大小取决于照片内容。干净的纯色图文可能使用无损压缩更小。当前逻辑固定按开关选择编码，**不会自动比较 JPEG 和无损结果再选更小者**。不是先降分辨率，也不会使用网页低分辨率预览图作为打印源。需要保留裁切后全部像素值时，取消勾选即可使用无损图片压缩；「无损」不代表撤销原图已有的 JPEG 损失或透视重采样。

### 黑白 PDF（灰度）

在右侧「排版与导出」中勾选「黑白 PDF（灰度）」，A4 布局里的卡面与水印会同步显示为灰度，下载文件名为 `身份证-A4-黑白.pdf`。取消勾选即可恢复彩色，不需要重新裁切。

这会将导出 PDF 中的四张卡面真正转为单通道灰度，水印文字也以灰度绘制，不只是网页显示滤镜或打印机选项。原照片不改动，上传卡面缩略图和裁切编辑仍显示彩色，尺寸、圆角、向内裁切、水印参数和 DPI 均保持不变。网页是低分辨率效果预览，最终打印色调以导出 PDF 为准。

灰度保留明暗层次，适合身份证复印效果；不是仅有纯黑、纯白的二值化。此选项作用于本工具新生成的 A4 PDF，目前不提供上传已有 PDF 再转换的入口。

### 用途水印

在右侧「排版与导出」中勾选「添加用途水印」，可输入最多 40 字的中英文用途说明（暂不支持 Emoji），并调整：

- **字号**：6–36 pt，默认 12 pt，直接决定打印文字大小。
- **角度**：-90° 至 90°，默认 -30°；负数表示文字从左下向右上倾斜。
- **密度**：1–5，默认 3；越大，重复文字的行距和列间距越小。
- **透明度**：0–95%，默认 75%；0% 不透明，数值越大越淡。

修改后稍候，A4 上四个卡面会同时更新水印预览。预览通过本机 PDF 渲染生成，与导出使用同一套字体、字号和排布。PDF 嵌入中文字体，不依赖阅读器安装相同字体；字体和渲染组件来自 PyMuPDF 依赖，不额外请求字体服务器。

水印只覆盖卡面，在圆角处裁切，不改照片的裁切范围或毫米尺寸。默认关闭；开关和参数不会写入浏览器持久存储。长文字、大字号或高密度可能挡住信息或被卡面边界截断，请根据预览调整。

水印是用途提示，不是防篡改或防删除机制。输出为叠加水印的 PDF，不会改动输入照片文件。

### 服务与隐私

- 默认且仅监听 `127.0.0.1`，无需账号，只供同一台电脑上的浏览器使用；不是公网部署方案。
- 照片发给本机 Python 服务，**不是纯浏览器计算**；不会发送到第三方。
- 不创建上传目录或临时照片文件，照片和 PDF 仅在请求内存中处理。页面不使用 localStorage、IndexedDB 等持久存储。
- 刷新或点击「清空全部」会清空页面中的照片；已下载的 PDF 不会被删除。内存释放不等于安全擦除，仍需注意系统交换空间、浏览器和操作系统的常规行为。
- 页面、接口和图片响应均设置 `Cache-Control: no-store`。请求检查 Host、Origin 和页面令牌，不允许其他网站跨域调用。
- 无外部 CDN、字体、统计脚本。请不要通过反向代理或隧道直接公开这个服务。
- 使用 Ctrl+C 停止服务。更换端口：`uv run web.py --port 8766`。

如果本机配置的 Python 包镜像报 `404`，可显式使用官方 PyPI：

```bash
uv run --index-url https://pypi.org/simple web.py
```

## 命令行版

不想使用网页时，也可以在项目根目录运行：

```bash
uv run id_card_pdf.py \
  "第一张正面.jpg" "第一张反面.jpg" \
  "第二张正面.jpg" "第二张反面.jpg" \
  -o "身份证-A4.pdf"
```

**推荐第一次加 `--review`**，逐张检查自动识别的绿色边框：

```bash
uv run id_card_pdf.py \
  "第一张正面.jpg" "第一张反面.jpg" \
  "第二张正面.jpg" "第二张反面.jpg" \
  --review -o "身份证-A4-确认版.pdf"
```

输入顺序决定排版，不会根据人像、姓名或文字自动分组：

```text
A4 竖版 210 × 297 mm

    第一张正面       第一张反面

    第二张正面       第二张反面
```

每个卡面均为 85.6 × 54 mm。两列间距 12 mm，两行间距 20 mm，整体居中。默认不添加标题、辅助线或额外文字；网页版可选择叠加用途水印。

## 自动识别不准时

```bash
uv run id_card_pdf.py \
  "第一张正面.jpg" "第一张反面.jpg" \
  "第二张正面.jpg" "第二张反面.jpg" \
  --manual -o "身份证-A4-手动版.pdf"
```

在本机桌面弹出的窗口中：

1. 左键点击卡片的四个**外角**，顺序不限；圆角处请选择直边延长线的交点。
2. 四角有效时显示绿色四边形，按 **Enter** 确认并处理下一张。
3. 按 **R** 清空重选；右键撤销最后一点；已有四点时再次左键会开始重新选择。
4. **Esc** 或关闭窗口取消整个任务，不生成 PDF。

`--review` 使用相同操作，自动检测成功时会预填四角；检测失败时让你手动选择。窗口是裁切边界预览，最终内容和方向请再打开 PDF 检查。`--manual` / `--review` 需要桌面图形环境，不适合无显示器的 SSH 会话。

### 照片已经裁得很准

使用 `--already-cropped` 跳过边缘检测，把整个输入图当作卡面。**仅用于四张图均已沿卡片边缘裁好的情况**；否则背景也会被缩进身份证尺寸内。宽高比明显不符时会拒绝处理。

### 某个卡面倒置

程序会把长边转为水平，但不做 OCR，不能区分内容正向和倒置。可用 `--rotate` 为四张卡面分别指定矫正后是否再转 180 度，例如只把第二张输入图转正：

```bash
uv run id_card_pdf.py \
  "第一张正面.jpg" "第一张反面.jpg" \
  "第二张正面.jpg" "第二张反面.jpg" \
  --rotate 0 180 0 0 -o "身份证-A4-方向修正版.pdf"
```

可搭配 `--review`、`--manual` 或 `--already-cropped`。

### 清晰度

默认 `--dpi 300`，每个卡面约 1011 × 638 pixels。可改成 `--dpi 600`，但放大不能恢复原图中缺失的细节。DPI 只影响 PDF 中图片的采样分辨率，**不会改变打印的毫米尺寸**。

## 1:1 打印的必要设置

1. 纸张选 **A4**，每张纸打印 **1 页**。
2. 选择 **实际大小 / Actual size / 100%**。
3. 关闭 **适合页面 / Fit / Shrink oversized pages**，以及无边距打印的自动扩张。
4. 首次打印建议用尺子量卡面，确认宽 85.6 mm、高 54 mm。

PDF 已声明 `PrintScaling=None`，但阅读器和打印机可能不遵守；文件中的尺寸可以精确设置，实际打印仍受驱动缩放与设备误差影响。

## 拍摄建议与限制

- 一张照片只拍一张卡面，四角都要完整入镜；卡片尽量占画面的较大部分。
- 用与卡片反差较大的纯色背景，避免透明卡套、手指遮挡、反光和严重倾斜。
- 自动检测结合颜色、边缘和形状，不验证图片是否确实为身份证。纯色背景使用外围背景色分离；复杂背景回退到轮廓候选。其他矩形物体仍可能被误选，重要用途请用 `--review`。
- 自动检测失败不会悄悄把整张照片当作卡片；会停止并提示手动裁切。
- 透视矫正可处理平面倾斜，无法恢复模糊、遮挡、裁掉的边缘或弯曲卡面。
- PDF 包含身份证敏感信息，请保存到安全目录，不要提交 Git 或上传公共服务。这里只忽略了本目录内常见照片和 PDF，其他输出目录需自行留意。
